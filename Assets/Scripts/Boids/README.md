# Boids Algorithm Module

## Overview
Implements the Boids flocking algorithm with four core behaviors:
- Cohesion (聚集)
- Separation (分离)
- Alignment (对齐)
- Escape/Flee (惊散)

## Files
- `BoidManager.cs` - Manages all boids in the system
- `Boid.cs` - Individual boid behavior and state
- `BoidBehavior.cs` - Core Boids algorithm implementation

# Fish Swarm Interactive System - 演示场景使用指南

## 快速开始

1. **打开场景**
   - 打开 `Scenes/DemoScene.unity`
   - 点击 Play 按钮

2. **自动创建**
   - DemoSceneSetup 脚本会自动创建所有必需业务
   - 场景 2 秒后自动启动

## 游戏简介

此演示场景箱带了完整的下列模块：

- **Boids 群体下漂** 算法
- **Fish 个体控制** 系统
- **Interaction 交互** 系统
- **Visual Effects 视觉效果**
- **Manager 管理** 系统

## 控制方法

### 键盘快捷键

| 按键 | 功能 |
|--------|----------|
| `Space` | 暂停/恢复游戏 |
| `R` | 重新开始游戏 |
| `ESC` | 返回菜单 |
| `+` | 添加一条鱼 |
| `-` | 移除最后一条鱼 |
| `T` | 触发逃散效果 |
| `S` | 停止逃散效果 |

### 鼠标/手指控制

- **LMB 或 Q**：模拟左手
- **RMB 或 E**：模拟右手  
- **WASD**：移动手
- **Space**：手上下移动
- **C**：手下移动

## 控制板功能

屏幕左上角的控制板提供了丰富逐个控制选项：

### 游戏控制
- ▶ 启动游戏
- II 暂停/恢复
- ↻ 重新开始
- < 返回菜单

### 游戏信息
- 实时游戏简介状态
- 剩余时间显示
- 鱼数量计数
- 游戏进度

### Boid 控制
- 添加/移除鱼群成员
- 清理所有鱼

### 交互控制
- 调整逃散半径
- 调整逃散强度
- 清顺逃散效果
- 停止逃散

### 视觉效果
- 启用/禁用所有效果
- 折腾控制
- 梨刀控制
- 爆炸按钮控制

## 场景配置

### 鱼群参数
- **初始鱼数**：50
- **游戏时间**：180 秒（可修改）
- **自动启动**：是
- **启动延迟**：2 秒

### 业务创建
- 自动创建 GameManager
- 自动创建 UIManager
- 自动创建 BoidManager
- 自动创建 InteractionController
- 自动创建 VisualEffectsManager

### 环境设置
- **水颜色**：青色（0.2, 0.6, 0.8）
- **雾密度**：0.15
- **环境光强度**：1.2

## 游戏流程

1. **场景载入**
   - DemoSceneSetup 脚本创建所有模块
   - 初始化场景环境

2. **自动启动（可选）**
   - 2秒后 GameManager 自动启动游戏
   - 创建模拟 50 条鱼

3. **游戏中（180 秒）**
   - 鱼我自由泳动
   - 手控制可以触发逃散
   - 年年看细节效果

4. **时间到（180 秒）**
   - 游戏结束
   - 显示最终分数和统计

## 参数调整

### 调整位置

1. **DemoSceneSetup 业务** (`Assets/Scripts/Demo/`)
   - 水颜色
   - 雾效设置
   - 环境光
   - 鱼数参数

2. **DemoControlPanel** 实时滑块
   - 游戏时间
   - 逃散半径/强度

3. **Inspector 中：**
   - BoidSettings (Boid 算法参数)
   - GameManager (游戏设置)

## 收集技巧

### 上子测试交互
1. 打开游戏
2. 控制板中点击"Test Escape (Center)"
3. 看我子向四周遁稳
4. 控制板里模拟手指位置、速度

### 视觉效果测试
1. 打开游戏
2. 控制板中点击"Trigger Burst"
3. 我子出现爆炸粒子效果
4. 管提效果强度

### 验证 Boid 算法
1. 点击"Add Fish"添加鱼
2. 点击"Remove Fish"移除鱼
3. 环指控制，查睡鱼群是否正常运作

## 故障排除

### 游戏不能启动
- 检查 Console 是否有错误
- 确保 BoidManager 存在
- 检查场景是否正常加载

### 鱼不动
- 检查 BoidSettings 是否配置
- 检查鱼是否会掉出场景
- 格子大小是否合理

### 上子不逃散
- 检查 InteractionController 是否鼠标位置正常
- 检查逃散半径设置（需要与算法整合）
- 检查 Escape 是否想会

### 肚表水水
- 看 Debug Log 检查系统初始化过程
- 三个控制板子一三知：
  - 向右上角的 GestureDetector 信息
  - 右上角的工作状态提示

## 扩展提示

3. **增加难度设置**

   - 添加不同场景

4. **损失为纷与困趣支配**
   - 增加分数排行榜
   - 加入游泳效果
